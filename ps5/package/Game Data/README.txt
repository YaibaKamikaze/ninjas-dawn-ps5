Ninja Gaiden II for PS5 - your game files go here.

No game files come with this app. You need your own Xbox 360 copy of
Ninja Gaiden II (title 544307D5), extracted from your disc image with a tool
such as extract-xiso, on your PC.

Copy the extracted files STRAIGHT INTO this folder over FTP, so that
default.xex sits directly in it (not in a subfolder):

  /data/homebrew/PPSA94202/Game Data/default.xex
  /data/homebrew/PPSA94202/Game Data/char.ng2
  /data/homebrew/PPSA94202/Game Data/cmn.ng2
  /data/homebrew/PPSA94202/Game Data/s_chap_01.ng2 ... s_chap_14.ng2
  /data/homebrew/PPSA94202/Game Data/*.wmv, *.xwb, *.xsb, ...

The $SystemUpdate folder is not needed. About 6.7 GB.

When you start the app, the hub checks this folder and tells you if anything
is missing or if it is a different game.
