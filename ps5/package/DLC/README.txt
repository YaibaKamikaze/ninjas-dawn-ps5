Ninja Gaiden II for PS5 - downloadable content (optional).

Put your own Xbox 360 DLC packages here: the extensionless files from
<content>\544307D5\00000002\ on your Xbox 360 or its storage (Fiend
Challenges, Shadow Walker, Biometal Hayabusa, Mission Mode).

  /data/homebrew/PPSA94202/DLC/<package files>

Open DOWNLOADABLE CONTENT in the hub to see and install them. START GAME
also installs any that are not installed yet. Installing twice is harmless.

Mission Mode needs the game's title update, which this version does not
support yet; the hub says so on the DLC page.
